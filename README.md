# Paddock Studio

JRA平地GⅠの展開を、馬柱を学習したLightGBMと3Dの馬で表示するWeb試作。
回収率・的中率は目的にも評価指標にも含めない。

## 現在の実装
- 指定フォルダのmykeibadbを読み取り専用で利用。DBの更新・変更は行わない。
- 各角の正規化通過順位4モデルと上がり3Fモデル。
- 完全な出走頭数と有効な馬名・レース名を持つデータを選別。
- 2025年8月までで学習、9〜12月で時系列検証。推論用は2025年末までで再学習。
- 2026年の正常なGⅠ10レースを掲載。対象レース結果は特徴量や学習に入れない。
- 過去走は対象日より前の最大5走。オッズ、人気、払戻をモデルに渡さない。
- 毛色・馬番・馬名・ブリンカー（青いメンコ）を表示。馬具不明は未取得として扱う。
- 3D再生、シーク、速度変更、馬群追尾カメラ（ドラッグで手動、「馬群を追尾」で復帰）、馬柱の閲覧。
- シークバーの背景にJRA公式の高低断面図を表示し、レース全体のどこを走っているかを示す。
- 実績再生とモデル予想を切替。実績は別ファイルreplays.jsonから読み込み、予測特徴量には渡さない。
- 実績再生は各角通過順位・入線順位に一致するよう補間。未観測コーナーを省略し、直線も入線順位まで変化する。

## 実行
```
npm run dev
python scripts/build_forecasts.py
python scripts/export_replays.py
python scripts/digitize_jra_courses.py   # JRA図面の読取（references/jra → app/courseData.ts, public/courses）
npx tsc --noEmit
node scripts/check_replay.mjs
```
Pythonはpymysql / pandas / numpy / lightgbm / python-dotenvが必要。
KEIBA_SOURCE環境変数で既存mykeibaのパスを指定できる。認証情報は既存設定をメモリー内で参照し、生成物には含めない。
モデルはmodels/、Web向け予想データはpublic/data/forecasts.json。

- モデルの位置予測は回帰値で、表の「番手相当」は重複する。3Dでは予測値順で並べる。

## 検証
TypeScript型検査・本番ビルド成功。ブラウザーで3D描画、再生/停止、馬柱選択、ダートレース切替を確認。コンソールエラーなし。
モデルの時系列検証値はmodels/report.jsonとWeb画面に表示。

2026-11-08 コース改善: 馬体長約2.4mと走路を同一縮尺に統一。3頭固定列を廃止し、連続した前後差と独立の内外位置を補間。馬群追尾は進行方向の側方から全体を収め、手動操作中は自動追尾を解除。選択時の馬体拡大を廃止しリング表示に変更。
`node scripts/check_geometry.mjs` で公式周長・高低差・経路連続性・発走〜ゴール接続・馬群配置範囲を検証。

2026-11-08 実績再生: 指定DBからCORNER1_JUNI〜CORNER4_JUNIとNYUSEN_JUNIを読み取り専用で別出力。タイムラインは記録の存在する角だけを表示し、各地点の隊列一覧を連動させる。NYUSEN_JUNI（入線順位）とKAKUTEI_CHAKUJUN（確定着順）は別項目として保持する。同順位はグループ扱い。
`node scripts/check_replay.mjs` は全10レースで観測順位と描画順位の一致、道中と直線での順位変化、欠けた角の省略、予想への実績混入防止、馬体のクリアランスを検証。東京優駿の5番が18→18→2→2→入線3位となる回帰テストを含む。

2026-11-08 コース改修: 中山・京都・阪神・中京もJRA公式平面図と高低断面図から自動読取（芝内回り・外回り・ダート）。トラックコードの外回り判定を修正（17=芝右は内回り、18=芝右外は外回り）。コーナー位置は図面の旋回角（45°/135°/225°/315°）から算出。
高低差は実寸だと平面に見えるため8倍に強調し（上り下りが走行中に分かるよう実寸には合わせない）、地面も各コースの高さに追従させた。坂で馬が地面や図形に埋まる不具合（東京の引込線ポリゴンが固定高さで坂の上に浮いていた）を修正し、地面は常に走路より下に置く。馬は見やすさのため約1.7倍（全長約4m）で表示し、位置取りの間隔も同じ比率で広げた。カメラは馬群追尾のみ。
`node scripts/check_geometry.mjs` は全掲載レースで公式周長・公式高低差・強調後の高さ・地面が走路より下にあること・経路連続性・馬の重なりを検証する。

2026-11-08 段差の解消: 断面図の1px段（約0.07m）が強調で段差になっていたため、断面は「平坦区間と一定勾配の坂」の折れ線に当てはめ、ほぼ平坦な区間は完全な平坦にそろえた。1周のつなぎ目（ゴール）の高さも一致させた。内回りと外回りは同じ図面縮尺で配置し、共有区間では外回りも内回りと同じ線・同じ高さを使う（中山で3%ずれて二重・段差になっていた）。
描画するコースは各場のJRA平地GⅠが使うコースのみ（東京・中京＝芝とダート、中山・京都・阪神＝芝の内回りと外回り）。障害走路と非GⅠのダートは描かない。
