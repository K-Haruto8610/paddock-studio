# JRAコース図面（他場）

取得元: https://www.jra.go.jp/facilities/race/<venue>/course/index.html（取得日 2026-11-08 JST）
対象: nakayama / kyoto / hanshin / chukyo。東京は tokyo/README.md を参照。

- pic_course_heimenzu.gif: 平面図。芝内柵・外回り内柵・ダート内柵を `scripts/digitize_jra_courses.py` が自動で読み取る。
- 芝・外回り・ダートの高低断面図（turf / turf2 / shiba_in / shiba_out / shiba / durt）: 断面図の塗りの上端を列ごとに読み取り、残り距離→高さの折れ線にする。

読み取り方法（digitize_jra_courses.py）
- 平面図: ダート帯の中心から放射状に走査。ダート帯の外縁を芝内柵、外側の囲まれた緑帯の内縁を外回り内柵とする。
  ダート内柵は距離表示の文字で欠けるため、芝内柵を図上のダート帯幅だけ内側へオフセットして作る。
  ゴール位置は図面の▲ゴールのx座標、走行方向は左回り/右回りから決める。
- 断面図: 図枠の上下端の目盛値（例 +4m / -4m）で高さを校正し、左右端を0mと1周距離に対応させる。読み取り値は平坦区間と一定勾配の坂だけの折れ線に当てはめ、高低差0.15m未満の区間は平坦にする。
- 対象はGⅠで使うコースのみ: 中山・京都・阪神は芝の内回り・外回り、中京は芝・ダート。外回りは内回りの線に外側のふくらみを足して作り、共有区間は完全に一致させる。
- 3Dでは各経路を公式周長に合わせて縮尺する。高さは8倍に強調して表示する（上り下りが走行中に分かるよう実寸には合わせない）。
- シークバー背景には断面図の図枠内を1周分切り出した public/courses/<venue>-<kind>.png を使う（進行方向が左→右、右端がゴールになるよう必要に応じて左右反転）。

図面は模式図であり測量座標ではない。外回りの分岐・合流付近や文字の重なる箇所は平滑化しているため数m程度の誤差がある。
目視確認用の重ね描きは outputs/course-digitize/ に出力される（git管理外）。
