# 追加指示12：天皇賞（秋）・エリザベス女王杯での遡及検証（v2.0、2020〜2026フレーム）

2026-11-19。branch `exp/h-retro-gi`（worktree `.claude/worktrees/h-retro`）。公開ファイル（`public/data`、`models/`）と
`pace_model.py` には触っていない。マイルCSの予想経路も未使用。2レースだけなので**数値の優劣で採否を決めるものではない**（再現度の確認）。

## 1. 何をしたか

対象レースごとに「その日時点の v2.0」を作り直した（`scripts/retro_gi.py`）。

- 学習・履歴・レーティングの材料は、保存済みの2020〜2026フレーム（`outputs/data-expansion-v20/frame_2020.pkl`）から**レース当日以降の行を先に捨てて**から作る。
  履歴特徴量（全過去走の指数加重平均ほか）・`rating_pre`（DBの全JRA平地、前日までの結果だけで更新）・コース標準（2025-06-01より前）・GIの3等分帯・コーナー集合は、すべてこの切り詰めた材料から作る。
- 全モデル（順位・馬身差・内外・上がり・ペース・隊列長・道中移動）を `fit_models(d, end=レース当日)` で学習し直した（`d.date < 当日`）。
- 予想は出馬表経路（`upcoming_rows`、マイルCSの予想が通る経路）：当日の出走馬・馬番・斤量・年齢・ブリンカー、各馬の前日までの過去走、前日までのレーティング状態。対象レースの結果はどこにも入らない。
- ポジション争いのパラメーターは公開中のv2.0の値（alpha 0.7, delta 0.04, front 0.25, hold 0.03, beta 1.0, k 3）。これは2025年6〜8月で選んだもので、対象レースを含みえない。予想レンジ（rankRange）は作り直していない。

## 4. 定性メモ（隊列図：`formation_tenno.svg` / `formation_queen.svg`、馬別表：`horses_*.md`）

### 天皇賞（秋）：ハイペースの方向と先行勢の顔ぶれは当たり、逃げ馬の取りこぼしとペースの強さが外れ

- **似ているところ**：先行争いの主役（純逃げ型の9・13、15・12）が先行集団に入る。後方の骨格も似る（最後方の14は一致、中団後ろに5・7・8・11・3が固まる）。勝った17は後方に置いたが、予想13番手に対し実際は16番手。前半は標準より速い（H）という向きも当たり。
- **違うところ**：
  1. **逃げ馬の有無**：実際の先頭は4レディネス（過去は中団寄りで逃げ率0.20、予想7番手）で、13と並んで2角を先頭で通過した。逃げ馬が「9・13」の予想に対し、実際は「4・13」の競り合い。4は結局17着、上がり37.2秒。
  2. **ペースの読み**：−0.91秒の予想に対し実際は−1.60秒。先行勢の失速（4: 37.2、13: 36.5、9: 35.9、2: 35.9、16: 35.6）は小さくしか出せなかった（4の予想34.6、13の予想34.8）。9だけは35.4（前日締め）〜36.3（v1.9公開）と近い。v2.0前日締めの方が失速の幅は小さい。
  3. **隊列の伸び縮み**：予想は2〜4角いずれも実際より縦長（前日締め：80%位置で+1.5〜2.7馬身、馬身差の偏り+1.6〜1.75。v1.9公開：+0.6〜1.8馬身、偏り+0.9〜1.1）。実際の4角は先頭5頭がほぼ一団、後ろに団子、最後方に14。前日締めはv1.9公開より長いが、v1.9仕様前日締めやv2.0現行公開も同じく長い（レーティングではなく、フレーム・ポジション争いの値の違い。どちらかへの切り分けはしていない）。
  4. 差し馬：勝った17ダノンデサイル（16番手 → 1着、上がり最速32.9）は予想も後方（13番手）だが、上がりは33.8予想。

### エリザベス女王杯：先行集団の顔ぶれは当たり、逃げ馬の誤認で隊列の伸縮が逆

- **似ているところ**：先行集団の顔ぶれ（6・1・10。予想の先行馬リストと3/5一致）、最後方の3・4・11（実際16〜18番手、予想14〜18番手）、差し馬15の後方待機（予想14〜15番手）。
- **違うところ**：
  1. **逃げ馬の有無**：予想の逃げ馬は8レーゼドラマ（近走5走中3走で1角先頭、逃げ率1.00）。実際は11番手に控え、15着。代わりに6ヴーレヴー→10セキトバイースト→（4角は10が先頭）の順に先頭が変わった。予想の逃げ馬が行かない場合の隊列は想定外（外れ値の1頭が隊列全体の前提）。
  2. **ペースの読み**：実際は遅め（+0.30秒、S）、予想は−0.58秒（M）。逃げ馬が不在で、先頭が1頭に決まらない遅い流れだった。
  3. **隊列の伸び縮み**：予想は1〜2角が長く（80%位置で9〜10馬身）、4角で縮む（4.4馬身）。実際は2角で詰まり（4.6）、3〜4角で伸びる（5.2→7.7、最後尾は先頭から約15馬身）。**伸び縮みの向きが逆**。遅い流れで中団が詰まり、直線入口で最後方が離れるという形をモデルが作れていない。
  4. 上がり：重の入力が上がり水準を約1.3秒遅く出した。実際は遅いペースの上がり勝負で全体に速かった（勝った15ラフターラインズは14番手から33.3）。馬場状態を伏せるとほぼ合う（偏り+0.35）。
  5. 7カムニャックは予想8〜9番手に対し、実際は2〜4番手の好位で2着。

### 2レース共通

- 違いの大半は「逃げ馬の特定」と「ペースの強さ」に集約される。どちらも過去走だけからは予想しにくい入力（4レディネスの逃げ、8レーゼドラマの控え）。
- レーティング（v2.0の変更点）は、位置の並びには目立つ効果がなく（4角τ +0.015／−0.054）、上がり3Fの水準・並びで一貫して良い方向（MAE −0.11／−0.25秒）。279レースの検証と同じ向き（上がり −0.024秒、4角τは小幅プラス）だが、2レースでは確かめられない。
- v1.9公開との差のうち、馬身差の悪化（天皇賞）はレーティングではなく、再調整したポジション争いの値と2020〜2026データによる。

## 5. 限界

- 2レースのみ。τ の標準誤差が0.1〜0.2程度で、差はほぼすべてその範囲内。
- 実績の馬身差・内外は通過順表記から復元した近似（記号の幅の中央値）。連続座標ではない。
- 馬場状態は当日朝の情報（記録値を使用）。枠順発表前のカードには入らない（その場合の挙動は「馬場不明」列）。エリザベスでは上がり水準を約1秒動かすほど効く。
- 予想レンジ（rankRange）は作り直していない。出馬表経路は出走馬の頭数をDBの出走馬で固定（取消・除外は当時の発走前の確定頭数に相当）。
