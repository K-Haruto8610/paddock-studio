## 変更
- 線形をデータ化(`app/alignmentData.ts` の `'05'`)。芝・ダートそれぞれ「直線 + 緩和曲線 + 円弧(2半径まで)」で、一周と最終直線は公式値に厳密に合わせた。
  ダートのゴールは芝より内側(案内図の 17px 内側)なので、コースごとの発走姿勢 `poses` を追加した。
- 高低を傾き連続の補間にした(京都と同じ。誇張倍率は東京は 8 倍のまま)。
- 手書きの芝の引込線ポリゴン `TOKYO_CHUTE_A/B/C` を廃止し、経路定義(`ROUTE_SPECS` の 3 本)から作る面に置き換えた(`tokyoChutes`)。
  芝の引込線は本線の面に重なる部分を省いて1枚につなぎ、ダートの引込線(芝を横切る)は芝の上に、ダートの面に触れる部分は省く。
- 重なり判定 `coveredBy` が走路の幅に届いていなかった不具合を直した(京都の外回りの省き方にも効く)。
- エプロン `TOKYO_APRON_*` は案内図の座標のまま残した(ラチと重ならないことを `apron.png` で確認)。
  東京のコーナー位置は従来どおり手書きの式(`checkpointDistances`)で、変更なし。

一定半径の円弧の下に収まらない。(更新)ダートの縮尺は一周 1899m に合わせて芝より 0.2% だけ自由にした(最初は芝と共有で最大 7.5px)。残りは3px超が最大 4.7px で、許容(3px)は超えたまま。
